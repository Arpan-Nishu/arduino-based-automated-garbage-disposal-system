# Changelog

## [1.0.0] — 2026-06-07

### Added
- Complete Arduino Uno sketch with full system logic
- HC-SR04 ultrasonic sensor integration for garbage level detection
- IR obstacle sensor for hands-free lid operation
- SG90 servo motor lid control with 5-second auto-close
- 16×2 I2C LCD display showing fill percentage and status
- Three-stage LED indicators (Green/Yellow/Red) for fill level
- Buzzer alert when bin reaches 90%+ capacity
- Serial debug output for real-time monitoring
- Comprehensive README with wiring diagram, pinout table, and usage guide
- Circuit diagram (Fritzing .fzz format)
- Pin configuration documentation
- Customization guide with configurable constants
- Simulation instructions for Wokwi
- Installation guide for Arduino IDE
